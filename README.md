# H-BANK

H-BANK is a simulated banking application built with HTML, CSS, and JavaScript.

The project allows users to create a mock bank account, make deposits and withdrawals, view transaction history, and keep their account data saved after refreshing the page.

## Live Site

[View H-BANK](https://h-bank-sigma.vercel.app/)

## Features

- Create a simulated bank account
- Generate an account number and sort code
- Generate a starting balance
- Deposit money
- Withdraw money
- Prevent invalid or excessive withdrawals
- View transaction history
- Save account data with localStorage
- Restore account data after refresh
- Reset account data
- Display success and error notifications
- Responsive layout for desktop, tablet, and mobile

## How It Works

When a user creates an account, the application generates an account number, sort code, and starting balance.

Deposits and withdrawals update the balance and are added to the transaction history.

The account and transaction data are saved in localStorage, allowing the application to restore the account after the page is refreshed.

The reset button clears the account, transaction history, and saved data.
